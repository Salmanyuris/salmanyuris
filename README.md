# 👋 Halo, Saya Salman Yuris!

Saya adalah seorang **IT Quality Assurance Junior** yang memiliki antusiasme tinggi dalam memastikan kualitas perangkat lunak, keandalan sistem, serta kenyamanan pengalaman pengguna. Dengan latar belakang di bidang **Web Development**, **UI/UX Design**, dan **Analisis Data**, saya menggabungkan perspektif teknis dan desain untuk melakukan pengujian produk digital secara komprehensif.

### 🛡️ Fokus Utama & Keahlian QA Saya:
- 🧪 **Software Testing Lifecycle (STLC)**: Perancangan skenario pengujian (*test cases* & *test scenarios*), pengujian fungsional/non-fungsional, serta pelaporan defect secara detail dan terstruktur.
- ⚙️ **Manual & Automated Testing**: Melakukan eksplorasi bug secara teliti dan mengotomatisasi pengujian API serta aplikasi web.
- 🔍 **Detail-Oriented & User-Centric**: Memastikan aplikasi berjalan lancar dengan UI/UX yang intuitif bagi pengguna akhir.
- 💬 **Collaborative Tester**: Bekerja sama erat dengan tim developer untuk mempercepat proses debugging dan rilis produk yang stabil.
